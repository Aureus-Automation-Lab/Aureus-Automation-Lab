# Code of Conduct

## Our pledge

We want this public repository to be a respectful, practical place to discuss controlled AI automation. Contributors, maintainers, and participants are expected to act professionally and to make room for different levels of experience, perspectives, and backgrounds.

## Expected behaviour

- Be constructive, specific, and considerate.
- Discuss ideas, evidence, and implementation rather than people.
- Respect public-safety boundaries: use synthetic examples and remove customer, credential, and private operational details.
- Accept feedback in good faith and help keep review discussions clear.

## Unacceptable behaviour

- Harassment, discrimination, threats, or personal attacks.
- Publishing private information, credentials, customer material, or information that could expose an operating environment.
- Misrepresenting work, evidence, attribution, or permissions.
- Disrupting collaboration through spam, abusive language, or deliberately misleading reports.

## Enforcement

Maintainers may remove content, close discussions, limit participation, or take other proportionate action when this code is not followed. If a discussion needs a private channel, open a minimal GitHub issue titled `Maintainer contact requested`; do not include sensitive details. A maintainer can then arrange the appropriate next step.

## Scope

This code applies to issues, pull requests, discussions, and other interactions associated with this repository.
