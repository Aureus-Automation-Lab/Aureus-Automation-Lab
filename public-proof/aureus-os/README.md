# Aureus OS Public Proof

This package explains Aureus OS in a public-safe way.

In plain language, **Aureus OS is the method Aureus uses to keep AI-assisted work controlled**. It gives tasks a scope, gives sensitive decisions a review point, checks outputs before trust, and keeps evidence so the next person can understand what happened.

![Aureus OS operating model](../../assets/aureus-os-model.gif)

It is designed for companies that want AI to help without turning work into scattered drafts, unclear decisions, and hidden risk.

## Problem Statement

AI output alone is not enough.

Serious company work needs:

- scope,
- ownership,
- review,
- validation,
- action gates,
- evidence,
- handoff.

## Operating Model Summary

```text
business task
-> scope and rules
-> AI prepares the work
-> person reviews sensitive parts
-> validation checks the output
-> approval gate stops risky actions
-> evidence is kept
-> handoff explains the next step
```

Open the [operating model](operating-model.md) for the full public-safe map.

## What Aureus OS Connects

Aureus OS connects:

- business goal,
- process boundary,
- AI assistance,
- Git / source-controlled work,
- workflow automation,
- validation,
- owner approval,
- evidence,
- handoff.

The point is not to make the system sound complicated. The point is to make work easier to trust.

## What Action Gates Do

Action gates stop sensitive work from moving forward without review.

They are especially important for external messages, public claims, financial handoffs, production workflow activation, and client-facing deliverables.

## What Evidence Means

Evidence means a record of:

- what was requested,
- what was produced,
- what was checked,
- what was approved,
- what is still risky,
- what the next step is.

For a buyer, this means the system is not only faster. It is easier to explain, audit, improve, and hand off.

## What Stays Private

Internal prompts, private repos, credentials, workflow IDs, private logs, customer data, endpoints, and private implementation details stay private.
