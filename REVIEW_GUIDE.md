# Review Guide

Use this guide to review the portfolio quickly.

Start with:

1. [README.md](README.md)
2. [CAPABILITIES.md](CAPABILITIES.md)
3. [CASE_STUDIES.md](CASE_STUDIES.md)

It is a public-safe portfolio for architecture thinking, AI automation design, review boundaries, and evidence-backed workflow delivery.
