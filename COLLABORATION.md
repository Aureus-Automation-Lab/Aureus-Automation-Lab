# Collaboration Brief

This document explains how a practical collaboration usually starts and what the first useful outcome should look like.

## Good Starting Inputs

Share the simplest honest version of the problem:

1. What process is too manual, slow, fragile, or unclear?
2. Which tools are involved today?
3. Who owns the process?
4. What currently breaks, gets delayed, or requires too much attention?
5. What would a useful first version prove?

## First-Slice Approach

The first build should be small enough to validate quickly and useful enough to change the workflow.

Good first slices often look like:

- a structured intake flow,
- a dashboard or review queue,
- an automation with manual approval,
- a document or data workflow with validation,
- an AI-assisted draft process with owner review,
- a product demo that helps test a real offer.

## Collaboration Phases

| Phase | Goal | Output |
| --- | --- | --- |
| Discovery | Understand the workflow and decision points | Process map, scope, assumptions |
| Design | Choose the smallest useful build | First-slice plan, success criteria |
| Build | Create the working version | Workflow, tool, dashboard, or prototype |
| Review | Check reliability and usability | Test notes, edge cases, risk review |
| Handoff | Make it usable without guesswork | Operating notes, next steps |

## Boundaries

Strong automation does not remove ownership. It should make ownership clearer.

I usually keep these boundaries explicit:

- what is automated,
- what remains human-reviewed,
- what data is sensitive,
- what can fail,
- who approves important actions,
- how the work is validated.

## Best-Fit Projects

Best fit:

- operational workflows,
- internal tools,
- AI-assisted review systems,
- document or data workflows,
- product and web prototypes,
- automation cleanup and handoff.

Less ideal as a first project:

- vague "automate everything" requests,
- production-critical changes without a review path,
- unclear ownership,
- work that requires exposing private systems before scope is agreed.
