# Profile Video Assets

This folder is reserved for future public-safe profile video assets.

No MP4 is committed in this pass. The profile uses static GitHub-safe images and SVGs, plus the video storyboard in `PROFILE_VIDEO_STORYBOARD.md`.

## Add A Video Only When

- the Azure/Sora route is available and owner-approved,
- the output passes public-safe review,
- the video contains no readable fake UI text,
- there are no secrets, endpoints, workflow IDs, private screenshots, client-like data, or provider badges,
- the file size is reasonable for GitHub,
- it does not imply customer proof, certification, production deployment, revenue, accounting correctness, or trading performance.
