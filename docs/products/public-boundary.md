# Public Boundary

This repository is a public product profile for Aureus Automation Lab.

It shows product direction, workflow maps, proof packages, review boundaries, and public-safe architecture.

## Safe to show

- product descriptions,
- public workflow maps,
- fictional buyer examples,
- review boundaries,
- public proof packages,
- general architecture models,
- public offer menu.

## Not public

This repository must not expose:

- private implementation,
- credentials,
- tokens,
- private connection URLs,
- private endpoints,
- raw workflow exports,
- private prompts,
- real invoices,
- real leads,
- message inbox data,
- production logs,
- client-like data,
- local computer paths,
- personal material,
- unsupported result claims.

## Claims boundary

This repository does not claim customer results, guaranteed ROI, accounting correctness, tax or legal advice, trading performance, enterprise compliance, or public access to private systems.

It is a public presentation of Aureus products and safe workflow thinking.
