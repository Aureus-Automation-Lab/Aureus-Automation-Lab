# Offer Menu

This menu explains what a client can buy first. It is intentionally practical: each offer starts with a business process, not with a tool.

## Recommended First Purchase

**Recommended first purchase: Automation Audit.**

Why: it is low-risk, maps the process first, and creates the basis for a scoped workflow build or monthly automation partnership.

Typical next step after the audit:

```text
Automation Audit
-> scoped workflow build
-> validation / handoff
-> monthly partner if useful
```

## 1. Automation Audit

| Field | Detail |
| --- | --- |
| Who it is for | A founder, operator, agency, or team that knows work is too manual but does not know what to automate first. |
| Problem it solves | The process is unclear, repeated, slow, or dependent on one person's memory. |
| What is delivered | Process map, automation candidates, risk/review points, first useful scope, and next-step recommendation. |
| What is not claimed | No promise that every step should be automated. No promised ROI. No production deployment claim. |
| Best next step | Send one process that wastes time or creates repeated mistakes. |

## 2. n8n Workflow Review

| Field | Detail |
| --- | --- |
| Who it is for | A team already using n8n or similar automation tools. |
| Problem it solves | Workflows run, but they are fragile, hard to explain, hard to change, or risky to activate. |
| What is delivered | Review notes, failure points, safety boundaries, naming/structure guidance, validation plan, and improvement path. |
| What is not claimed | No live activation without explicit approval. No exposure of credentials, endpoints, workflow IDs, or private exports. |
| Best next step | Share a sanitized description of the workflow and the failure you are worried about. |

## 3. n8n Workflow Automation Build

| Field | Detail |
| --- | --- |
| Who it is for | A business with a repeated workflow that should be controlled, reviewed, and easier to maintain. |
| Problem it solves | The team repeats the same steps manually or uses a workflow that lacks review, state, and evidence. |
| What is delivered | Workflow design, automation logic, review boundary, validation notes, handoff documentation, and operating guidance. |
| What is not claimed | No blind sending, hidden external actions, or unmanaged production changes. |
| Best next step | Start with one repeated workflow and define the desired business output. |

## 4. FinEcon Paid Pilot

| Field | Detail |
| --- | --- |
| Who it is for | Teams handling invoices, documents, finance inputs, reporting, or accounting-adjacent review. |
| Problem it solves | Documents arrive in messy formats and move through unclear review or handoff paths. |
| What is delivered | Reviewed document-flow direction, intake/review states, exception handling, proof notes, and next-step handoff design. |
| What is not claimed | FinEcon does not replace accounting review, tax/legal advice, or professional responsibility. |
| Best next step | Pick one document flow and define what a person must approve before downstream use. |

## 5. AI Operating System Setup

| Field | Detail |
| --- | --- |
| Who it is for | A team that wants to use AI across work without losing control of scope, review, and evidence. |
| Problem it solves | AI outputs are scattered across chats, docs, automations, and tools without clear ownership. |
| What is delivered | Operating model for scope, constraints, review gates, validation, evidence, handoff, and next actions. |
| What is not claimed | This is not a claim that AI can safely run the company alone. |
| Best next step | Define the first area where AI should help but not act as final authority. |

## 6. Monthly Automation Partner

| Field | Detail |
| --- | --- |
| Who it is for | A company that wants ongoing automation improvement instead of one-off scripts. |
| Problem it solves | Automations age, break, lose context, or stop matching how the business works. |
| What is delivered | Monthly review, improvement backlog, workflow changes, documentation updates, validation notes, and controlled iteration. |
| What is not claimed | No unlimited production responsibility without a scoped agreement and approval process. |
| Best next step | Start with an audit or one paid pilot, then decide whether monthly support makes sense. |

## Recommended Entry Path

```text
Automation Audit
-> scoped workflow build
-> validation / handoff
-> monthly automation partner if useful
```
