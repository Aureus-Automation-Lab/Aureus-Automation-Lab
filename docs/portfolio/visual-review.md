## Visual Checklist

- [x] clear first impression
- [x] one-line positioning visible
- [x] one main architecture visual
- [x] no overclaiming
- [x] no private data
- [x] public demo flow exists
- [x] offer menu exists
- [x] GitHub-safe GIFs render without external images or fonts

## Quality Bar

The visual system should feel:

- calm,
- premium,
- structured,
- readable at GitHub width,
- useful to a non-technical buyer,
- credible to a technical reviewer.

Avoid:

- random decorative graphics,
- fake dashboards,
- fake metrics,
- stock-photo people,
- cluttered flowcharts,
- unsupported certification or customer-proof visuals.
