# Public Boundary

This repository is a public portfolio, not a private implementation dump.

## Safe To Show

- positioning,
- architecture diagrams,
- offer menu,
- demo flows,
- public-safe case study directions,
- review boundaries,
- validation thinking,
- evidence/proof-pack structure,
- sanitized examples.

## Not Public

- credentials,
- API keys,
- tokens,
- webhook URLs,
- private endpoints,
- raw workflow exports,
- workflow IDs,
- real invoices,
- real leads,
- client-like records,
- production logs,
- private prompts,
- private screenshots,
- POHODA access details,
- customer or revenue claims without separate verification.

## Claim Boundary

The public profile shows how the work is designed and reviewed. It does not claim private production outcomes, accounting correctness, official certification, tax/legal advice, trading performance, or guarantees about financial results.

For the deeper public boundary library, see [public boundary detail](../proof/public-boundary.md).
