# Support

Use the public-profile feedback issue form for reproducible documentation
problems, broken links, accessibility concerns, or public-safe improvement
suggestions.

This repository is a public portfolio and proof surface. It is not a production support channel
for private Aureus systems, client workflows, credentials,
billing, POHODA, or live automation incidents.

Do not include secrets, private customer information, production logs, or
access details in an issue. Follow [SECURITY.md](SECURITY.md) for security or
sensitive reports.
